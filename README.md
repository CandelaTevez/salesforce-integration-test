# Salesforce Integration Test

Repositorio de prueba para la integracion entre **Brandtrack** y **Salesforce**.

## Objetivo

Testear la sincronizacion de datos entre el backend Laravel de Brandtrack y Salesforce CRM.

## Flujos planeados

- Sincronizacion de cuentas (Accounts)
- Sincronizacion de suscripciones
- Webhooks de eventos

## Stack

- Laravel (PHP)
- Salesforce REST API
- OAuth 2.0
